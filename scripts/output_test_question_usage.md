# `output_test.jsonl` 每题 turn 与 token 统计

- 数据来源：`/mnt/ceph_rbd/data/avqa_project/daily_omni/OmniAgent_repeat1/output_test.jsonl`
- Question sample 数：**1,197**（`question_id` 均唯一）。
- 统计口径：每行 `question_data` 是一个 question sample；一个 `turn_trace` 条目记为一个 turn。`tool call step` 按 `planner_action == "tool"` 计数。`excluding final` 按总 turns 减去 `planner_action == "final"` 计数。
- Token 口径：逐题累加每个 turn 的 `planner_response.generations[0].usage_metadata.input_tokens` 和 `output_tokens`；这是 planner 模型调用的 token 用量，不包含 `perception_calls` 所用模型的 token。
